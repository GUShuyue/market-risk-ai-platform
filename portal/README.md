# AI 市场风险管理平台 · 统一入口

整合三个风险管理系统的前端页面，提供统一入口门户。

## 三个系统

| 系统 | 前端技术 | 默认端口 | conda 环境 | 启动命令 |
|------|---------|---------|-----------|---------|
| A股指数成份股调整预测（CSI 300） | FastAPI + 静态页 | 8000 | `index_predictor` | `python main.py --api` |
| 港股通股票标的池监控系统 | FastAPI + 静态页 | 8001 | `ht_proj` | `python main_chat.py --api --port 8001` |
| 播客舆情分析系统 | Streamlit | 8501 | `podcast_agent` | `python -m streamlit run src/podcast_agent/web/app.py` |

## 使用方式

### 方式一：一键启动（推荐）

双击运行 `start_all.bat`，脚本会自动：
1. 用各自对应的 conda 环境启动三个系统（端口 8000 / 8001 / 8501）；
2. 用默认浏览器打开 `portal/index.html` 门户页。

- 三个 conda 环境的 python 路径已内置在 `start_all.bat` 顶部（`index_predictor` / `ht_proj` / `podcast_agent`）。
- 若你的 conda 安装路径不同，编辑 `start_all.bat` 顶部的 `PY_CSI` / `PY_HK` / `PY_POD` 变量即可。
- 关闭某个服务窗口即停止对应系统。

### 方式二：手动启动

先用 conda 激活对应环境，再在三个系统目录执行上表中的启动命令，然后打开 `portal/index.html`。

## 门户页功能

门户采用**工作台（Console）外壳**：左侧常驻导航栏（概览 + 三个模块 + 内部平台标识），顶部标题栏显示当前模块，主区为概览或模块视图。面向**非开发岗位**使用者设计，弱化技术细节、强调"服务状态可见"。

- **服务状态探活（只读）**：门户加载时对各系统地址做轻量探测（no-cors fetch，不改动系统逻辑），侧栏模块项、概览卡片、聚合状态条三处均显示 ●运行中 / ○未启动 / ○检测中，打开前即知该不该点。
- **概览**：三张模块卡片（含状态标签）+ 下方聚合状态条（显示运行中/未启动汇总与图例，可一键刷新）；页面移除模型性能指标（F1 / 板块数等），相关内容收归各模块「说明」抽屉。
- **说明抽屉**：右上「说明」按钮在门户内右侧抽屉展示该模块的功能与逻辑（不再新窗口跳走）。
- **加载与兜底**：进入模块显示加载态并提示"若长时间无响应说明服务未启动"；7 秒无响应自动提示「模块服务未启动」，给出"联系 IT 运维"指引，启动命令收进可折叠的「技术人员」详情，不再直接甩给使用者。
- **部署与启动**：原"快速上手"的终端命令移至概览页底部「部署与启动（技术人员）」折叠区，默认不展示给普通用户。
- **地址设置（运维）**：右上角齿轮图标，可修改访问地址（默认端口见上表），配置保存在浏览器本地；普通用户无需操作。

## 说明

- 门户页为纯静态页面，不修改任何系统原有逻辑，三个系统保持独立运行。
- 若内嵌区域空白，说明对应系统尚未启动，按状态条中的启动命令启动即可，或点「新窗口打开」直接访问。
