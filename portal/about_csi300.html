A股指数成份股调整预测系统

CSI 300 Constituent Adjustment Prediction
量化规则大模型研判多 Agent可回测
系统目标 · Target
提前预测沪深300指数的半年度成份股调整，获取调入 / 调出 / 备选名单。
成份股调整会引发指数基金、ETF 等被动资金的集中调仓，提前预判调入调出，可帮助投研与交易部门把握调仓资金流向——捕捉调入个股的增量资金机会、规避调出个股的抛压风险。
  • 量化排名：用编制规则（成交额排名 + 市值排名 + 缓冲区规则）得到可能调入调出的股票
  • 大模型研判：基于候选排名 + 候选股财务数据（净利润、ROE、负债率、审计意见）综合研判调入调出
  • 回测验证：对比实际调整，量化预测准确率

运行逻辑

半年度（6月 / 12月）预测沪深300成份股调入调出，自然语言入口识别意图后分派到「预测调整」或「回测验证」两条独立链路，核心链路：数据采集 → 量化筛选与排名 → LLM 研判 → 预测报告。
1
数据采集DataAgent
1
时间点数据隔离 原则
严格「不看未来数据」——所有采集数据均不超过数据截止日 cutoff_date（如 6 月调整对应 4 月 30 日）。
2
量化数据并发采集
三路并发：指数成分股快照、全市场行情（市值 / 成交额 / 上市信息），供排名与阈值模型使用。
akshare / tushare 可切换
3
定性数据并发采集
财务数据（净利润、ROE、负债率、审计意见）、停牌等事件、价格变动、行业分布。其中候选股财务数据后续会组装进大模型的上下文。
4
关注池裁剪
只对「调整前成分股 + 市值前 600」做定性数据采集，避免全市场扫描过慢。
2
量化筛选与排名RuleAgent · RankModel
1
准入筛选
排除 ST/*ST、北交所股票、上市时间不足（科创 / 创业板需满 12 个月）、财务亏损（仅非成分股，科创板除外）。
2
成交额排名 · 剔除后 50%
先按日均成交金额降序，剔除后 50%；老样本额外享有成交额缓冲区（排名前 60% 保留）。
3
市值排名
再按日均总市值降序排名。
4
缓冲区选样
按「缓冲区」规则给每只股票打选样优先级，取前 300 只，确定调入 / 调出 / 备选名单。
样本 300新样本优先线 240老样本保留线 360
3
LLM 研判PredictAgent
1
组装 LLM 上下文
把当前成分股列表、候选排名（市值 + 流动性 + 缓冲区标记）、准入检查结果、候选股财务数据、量化结果、编制规则组装成 prompt。
2
大模型研判
大模型基于排名识别调入调出，并结合候选股财务数据（净利润、ROE、资产负债率、是否亏损、审计意见）做定性判断，输出调入 / 调出 / 备选名单及置信度、理由。
3
结果校正回填
用排名数据回填 LLM 输出的股票名称与代码，修正「待核实」等错误名称、补全交易所后缀，保证后续回测能正确匹配。
4
预测报告report_agent · llm_report_agent
1
预测报告 + LLM 分析报告
生成 HTML 预测报告（调入 / 调出明细 + 可视化），并额外由大模型生成分析报告。
5
回测验证（独立分支）backtest_agent
1
加载历史预测
从磁盘读取已保存的 prediction JSON。识别为回测指令后立即执行，不重跑量化预测链路。
2
获取实际调整名单
从数据源拉取官方公布的实际调入调出记录。
3
对比评估与偏差归因
计算调入/调出的精确率、召回率与 F1，并分析预测偏差原因。
4
生成回测报告
输出回测评估报告（HTML），含评估结果与偏差分析。

缓冲区规则（关键参数）

量化选样的核心，保证指数样本稳定、降低换手。
参数取值含义
sample_count300指数固定样本数
buffer_in240新样本市值排名 ≤ 240 优先进入
buffer_out360老样本市值排名 ≤ 360 优先保留
老样本成交额线前 60%被成交额后 50% 剔除的老样本，成交额排前 60% 可保留

技术栈

数据层
多数据源切换
akshare（免费）/ tushare（付费需 key），配置驱动，统一采集接口。
并发采集
线程池并发拉取量化与定性数据，提升采集速度。
量化层
缓冲区优先级模型
RankModel 多层优先级算法，把编制规则固化为可计算逻辑。
规则可配置
编制规则写在 YAML frontmatter + Markdown，RuleParser 解析，改规则不改代码。
AI 层
LLM 研判
基于候选排名 + 候选股财务数据（净利润、ROE、负债率、审计意见）让大模型综合研判调入调出。
LLM 分析报告
大模型生成可读的分析报告，输出调整逻辑解读。
编排层
配置驱动多 Agent
skill.md 定义工作流，AgentRegistry 注册，Orchestrator 通用执行引擎按步骤调度。
自然语言意图
正则映射自然语言到预测 / 回测工作流。

技术亮点

量化 + LLM 双引擎
量化定「谁进谁出」，大模型定「该不该」，覆盖纯量化难判断的灰色地带。
严格防未来函数
所有数据以 cutoff_date 隔离，回测结果可信，不偷看未来。
规则即配置
编制规则独立成文件，扩展新指数只需新增规则与 Agent 注册。
