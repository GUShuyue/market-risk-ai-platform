港股通股票标的池监控系统

Hong Kong Connect Stock Pool Monitor
双模式规则扫描量化预测自然语言交互
系统目标 · Target
持续监控港股通标的池，并提前预测标的调入 / 调出，识别风险与机会。
港股通标的的纳入 / 剔除直接决定南向资金的配置范围，提前预判可把握标的调整带来的资金流入机会，并预警调出风险、避免持仓踩雷。
  • 模式 A 扫描：可每日触发运行，全市场监控，预警短期内有可能进入或调出港股通的股票
  • 模式 B 预测：基于恒生综合指数的半年期成分股检讨预测，产出批量的港股通股票标的调入调出名单

运行逻辑

一句话操作整个系统：自然语言识别意图后，分派到「模式 A 持续扫描」或「模式 B 预测 / 回测」两条链路。
1
自然语言入口ChatHandler
1
混合意图识别 正则 + LLM
先正则快速匹配标准说法（「扫描」「预测 2026-03」「回测」），匹配不到再交大模型兜底理解非标准说法。
2
自然语言交互
前端页面可以直接使用自然语言交互，识别不同意图：scan（扫描）、predict（预测）、backtest（回测），并支持多轮上下文继承（预测做完后继续提交「回测呢」可以沿用上一轮的结果）。
2
模式 A · 持续预警扫描HkConnectMonitor
1
多数据源接入 AkShareDataProvider
整合 akshare 接口数据、上交所港股通标的清单和调整记录、恒生综合指数官网成分股和调整数据。
2
规则引擎评估 RuleEngine
逐股检查四类条件：① 排除条件（A+H 股 A 股 ST/退市、非港币报价）；② 第二上市不可纳入；③ WVR 首次纳入（上市满 6 个月 + 183 日日均市值 ≥200 亿 + 成交额 ≥60 亿）；④ 小型股市值门槛（前 12 月均市值，调入线 ≥50 亿 / 调出线 <40 亿）。
3
全市场扫描 HkConnectMonitor
遍历当前港股通标的池和港股市场，输出风险清单与 HTML 扫描报告。
3
模式 B · 调入调出预测OrchestratorB
1
构建选股范畴 UniverseBuilder
计算截止日前 12 个月日均市值，过滤 HDR、外国公司第二上市、上市不足 90 天的股票。
2
换手率测试 TurnoverTester
按编算总则做流动性测试，过滤低换手率候选（仅过滤调入，不影响覆盖率计算）。
3
月末市值计算 MonthEndMarketCap
计算月末时点市值，用于港股通小型股市值门槛判断。
4
HSCI恒生综合指数成分股调整预测 HSCICoverageModel
按市值覆盖率排序，预测 HSCI 成份股调入 / 调出，考虑覆盖率阈值与缓冲区状态。预测结果区分恒生综合大型、中型、小型股指数。
5
港股通映射 StockConnectMapper
把 HSCI 变化映射到港股通，做资格检查（恒生综合小型股指数的成分股需进一步检查考察期内平均月末市值 / 不同投票权架构的公司股票首次纳入要额外满足其他条件 / A+H 等），输出调入调出与不合资格名单。
6
LLM 报告 LLMReportGenerator
大模型基于预测结果生成 Markdown + HTML 分析报告。
4
回测验证BacktestAgentB
1
双层对比
Layer 1 对比 HSCI 预测与实际调整，Layer 2 对比港股通映射与实际，输出精确率 / 召回率 / F1 与偏差分析。

技术栈

数据层
多数据源融合
akshare + 上交所 + 恒生指数官网下载数据。
历史快照重建
从上交所和恒生综合官网下载的当前标的清单、成分股清单以及历史调整操作触发，反推某个历史时间点的标的和成分股清单。
量化层
规则引擎
HSCI / 港股通编制规则固化为可执行逻辑，逐股评估。
覆盖率 + 换手率模型
市值覆盖率排序 + 流动性换手率测试，构成预测链路。
AI 层
LLM 意图识别
正则快速通道 + 大模型兜底的混合意图识别，支持多轮对话。
LLM 报告生成
基于预测 / 回测结果生成结构化分析报告。
编排层
三路统一分派
自然语言入口识别意图，统一分派到模式 A 扫描、模式 B 预测、模式 B 回测三条链路。

技术亮点

双模式架构
「持续扫描预警」与「预测回测」独立又统一，覆盖监控与研判两类场景。
混合意图识别
标准说法正则秒回，非标准说法大模型兜底，兼顾速度与理解力。
多数据源融合
整合 akshare、上交所港股通标的数据、恒生综合指数官方 PDF 转换数据。
