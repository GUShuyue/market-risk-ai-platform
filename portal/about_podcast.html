播客舆情分析系统

Podcast Public Opinion Analysis
Multi-AgentLangGraphRAG 跨市场ASR 转录
系统目标 · Target
把英文财经播客内容转化为可用的 A 股投资信号。
海外财经播客常含对市场热点的深度解读与领先观点，将其结构化并映射到 A 股概念板块与个股，可为研究员补充增量信息源、辅助投资决策。
  • 语音转录：千问音频大模型把播客转成文字
  • 舆情研判：情感分析 + 实体证据抽取
  • 跨市场映射：关联 A 股概念板块与代表性个股

运行逻辑

LangGraph 编排的 7 个 Agent 协作：采集 → 转录 → 逐集分析 → 报告。核心是「播客音频 → 舆情结论 → A 股板块影响」的完整链路。
1
采集Collector
1
播客节目获取
通过 Listen Notes API 搜索并采集目标播客的节目；也支持直接读取本地 MP3 文件（绕过 API）。
2
转录Transcriber
1
语音转文字 qwen-audio ASR
DashScope 云端 ASR（qwen-audio-3.0-asr-flash-filetrans），异步提交任务 + 轮询等待，产出逐字稿 transcript 与句子分段供下游分析。
3
逐集分析（每集独立运行）Sentiment → Analyst → CrossMarket
1
情感研判 Sentiment
大模型（LLM）作为主引擎决定情感分数与标签（看涨 / 看跌 / 中性），并提取正负面因素与对冲语言；FinBERT 仅在大模型调用失败时兜底，不参与正常流程的情感打分。
2
证据分析 Analyst
大模型抽取关键实体与观点，并保留原文逐字引用（evidence），确保结论可追溯。
3
跨市场映射 CrossMarket
retrieve-then-generate 三段式传导：① 大模型从播客内容提取受影响主题词 → ② 对东方财富概念板块做子串检索得到候选 → 大模型从候选中选定标准板块名 → ③ 大模型为每个板块生成 3–5 只代表性个股（行业龙头），供重点关注。
4
长文本分块 Map-Reduce
整期播客文本过长时，按句边界切分为重叠块，逐块独立分析后加权合并，避免大模型上下文截断。
chunk 4000 字符overlap 500
4
报告生成Reporter
1
汇总成稿
合并各集分析结果，输出 HTML 分析报告（情感分布、实体观点、板块影响）。

关键参数

参数取值说明
CHUNK_SIZE4000 字符Map-Reduce 每块目标长度（英文约 2000 tokens）
CHUNK_OVERLAP500 字符块间重叠，保持上下文连续
llm_concurrency可配置全局并发信号量，控制同时进行的 LLM 调用上限

AI 技术栈

数据层
Listen Notes API
播客搜索与节目元数据采集。
本地 MP3 接入
绕过 API 直接分析本地音频文件。
感知层
ASR 语音转录
qwen-audio-3.0 ASR（DashScope 云端），异步提交 + 轮询，本地 MP3 上传后云端转写。
金融情感模型（兜底）
FinBERT 金融领域预训练模型，仅作 LLM 不可用时的兜底，正常流程由大模型决定情感。
AI 层
LLM 证据抽取
大模型分析师抽取实体与观点，保留原文逐字引用，结论可追溯。
RAG 跨市场映射
retrieve-then-generate 三段式：主题词 → 概念板块子串检索 → LLM 选定板块 → LLM 生成代表性个股。
编排层
LangGraph 状态图
7 个 Agent 协作，共享实例 + 全局并发信号量控制 LLM 调用。
Map-Reduce 分块
长文本按句边界切块，逐块分析后合并，稳健处理整期播客。

技术亮点

多 Agent 协作
采集、转录、情感、分析、跨市场、报告各司其职，由 LangGraph 统一编排。
证据可追溯
每个结论保留播客原文逐字引用，研究员可回溯验证。
跨市场映射
把播客内容自动关联到 A 股概念板块，打通「舆情 → 市场」链路。
长文本稳健
Map-Reduce 分块 + 并发控制，处理整期长文本不截断、不超限。
